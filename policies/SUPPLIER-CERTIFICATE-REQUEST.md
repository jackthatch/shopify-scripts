# Supplier NRTL certificate request
Generated 2026-09-28

Send this to the supplier for every mains-powered product before listing or relisting it.
Copy-paste ready. Chinese suppliers understand "UL certificate" and "file number" - asking in
those exact terms gets a much better response than asking about "safety certification".

## Message text

> Hello,
>
> Before we can list this product for sale in the United States, we need the North American
> safety certification documentation. Please provide the following for the **120V US version**
> of this product:
>
> 1. The **NRTL certificate** (UL, ETL/Intertek, or CSA) as a PDF.
> 2. The **file number** - the "E-number" printed on the certificate (for example E123456).
> 3. The **model number(s)** the certificate covers. Please confirm this exact model is on it.
> 4. The **safety standard** it was tested to. For lighting we expect **UL 1598** (fixtures),
>    **UL 153** (portable lamps), or **UL 8750** (LED drivers).
> 5. A **photograph of the product label** showing the certification mark and the model number.
>
> Please note: **CE, RoHS, FCC and "CE-certified" are not accepted for the US market.** We
> require a mark from an OSHA-recognised Nationally Recognized Testing Laboratory (NRTL).
>
> If the product is only available with a CE mark, please tell us clearly and we will not list
> it. We would rather know now than ship product we cannot legally sell.
>
> Thank you.

## Verification steps - do these yourself, do not skip

A certificate PDF can be forged, reused from a different product, or expired. Always:

1. **UL Product iQ** (ul.com, free registration) - search the file number, or the company name,
   or the model number. Confirm the listing status is **active** and check the **expiry**.
2. **Intertek ETL Directory** - same logic if the mark is ETL.
3. **CSA product listing database** - same logic if CSA.
4. **Check the standard matches the product type.** A **UL 8750** listing covers an LED driver
   as a component. It is **not** a **UL 1598** fixture listing. A listed driver inside an
   unlisted fixture does not make the fixture listed.
5. **Check the model number on the certificate against the model you are buying.** Suppliers
   routinely send a certificate for a similar-but-different product.

## Red flags

- Only a CE mark, no NRTL mark
- A certificate with no file number
- A file number that returns nothing in UL Product iQ
- A "certificate" that is actually a self-declaration or a test report from a non-NRTL lab
- A certificate whose model number does not match the product you are buying
- Refusal to provide the file number

## Decision rule

**No certificate, or a certificate that fails verification = do not list the product.** This
single rule does more to protect the business than every other measure on this list.
